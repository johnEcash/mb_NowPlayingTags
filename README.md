# mb_NowPlayingTags
A Musicbee Plugin that exports Artist - Title - Album and a cover Image so it can be used with other software, In my case Stream Deck. (https://github.com/johnEcash/beedeck)

Configurable locations for NowPlaying.txt and the cover image.

NowPlaying.txt format:
<pre>
artist=Burial
title=Homeless
album=Untrue
love=0
</pre>
